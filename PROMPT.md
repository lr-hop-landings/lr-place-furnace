# СОЗДАНИЕ ПОДРОБНОГО ТЕХНИЧЕСКОГО ЗАДАНИЯ ДЛЯ РАЗРАБОТКИ ЛЕНДИНГА для услуги «Ленремонта»: восстановительная очистка / полировка варочных поверхностей от нагара, пятен и следов пригорания

Составь максимально точное, качественное и проработанное Техническое задание, которое обязательно должно включать в себя следующие разделы: 

## СТРУКТУРА ЛЕНДИНГА
Данный раздел должен содержать подробное описание всех блоков лендинга, их последовательность и назначение. Важно: лендинг не должен содержать header и footer. Лендинг должен быть одностраничным. Тексты в файле seo-copy-installation-metal-furnaces.md

## ТРЕБОВАНИЯ К ДИЗАЙНУ
Нужно предложить несколько концепций визуальных и сойтись к единой которая будет на всем сайте. Также нужно разработать дизайн-систему, стили, которые будут переиспользоваться при разработке в рамках сайта. Обязательно мобильная адаптация

## ТРЕБОВАНИЯ К РАЗРАБОТЧИКУ
Важные требования к разработчику: 
1. Проект реализовать на Astro. Использовать компонентный подход и четкое разбиение на папки и зависимости (Island Architecture)
2. Не использовать Tailwind CSS. Для названий классов предпочтительна методология БЭМ. Использовать scss или модульный подход - в зависимости блока и удобства
3. Все медиафайлы (фотографии, видео и т.д.) должны быть оптимизированы в соответствии с современными стандартами веб-разработки
4. Для слайдеров использовать библиотеку Swiper js
5. Для лайтбокса использовать библиотеку Glightbox js
6. Все формы делать в соответствии с файлом FORMS.md
7. При разработке опирайся на DEV_RULES.md
8. Проект реализовать в текущей директории

## ФИНАЛЬНЫЙ РЕЗУЛЬТАТ
Ты должен создать файл {project-name}-working-plan.md содержащий в себе максимально точное, качественное и проработанное Техническое задание, которое обязательно должно включать в себя все вышеперечисленные разделы. Большие инструкции можешь не переписывать в один файл, а оставить в рамках существующих файлов, но обязательно сослаться на них в итоговом ТЗ
