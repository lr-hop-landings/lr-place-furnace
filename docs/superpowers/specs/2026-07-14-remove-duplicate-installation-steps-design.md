# Удаление дублирующего блока этапов установки

## Контекст

Block12 «Как проходит установка металлической печи» повторяет смысл уже оформленного выше подробного маршрута монтажа. Повтор не добавляет новой информации и удлиняет страницу перед блоками доверия.

## Решение

Удалить Block12 целиком без замены новым контентом и без редизайна соседних секций.

В изменение входят:

- импорт `steps-numbered-grid-01.astro` из страницы;
- объект данных Block12 с заголовком, подзаголовком и шестью этапами;
- рендер `<Block12 ... />`;
- компонент `steps-numbered-grid-01.astro`, если после удаления он не используется в проекте.

После удаления социальный блок с предложением прислать фотографии должен непосредственно переходить в блок «Ответственность компании».

## Ограничения

- Содержимое и визуальный стиль соседних блоков не меняются.
- Порядок оставшихся секций сохраняется.
- Индексы `blockProps` корректируются только в местах, затронутых удалением объекта данных.
- Новые компоненты, тексты и декоративные элементы не добавляются.

## Проверка

- В странице отсутствуют импорт, данные и рендер Block12.
- Удалённый компонент больше не существует и не импортируется.
- В DOM социальный блок непосредственно предшествует блоку ответственности компании.
- Страница не получает лишнего вертикального промежутка на десктопе и мобильном.
- Существующие регрессионные сценарии, `astro check` и production-сборка проходят.
