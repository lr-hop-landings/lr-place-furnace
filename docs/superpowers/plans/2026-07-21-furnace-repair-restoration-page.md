# План реализации страницы ремонта и реставрации печей

Основание: `docs/superpowers/specs/2026-07-21-furnace-repair-restoration-page-design.md`.

## 1. Подготовить отдельный маршрут и контент

Файлы:

- создать `src/pages/remont-i-restavratsiya-pechey.astro`;
- переиспользовать существующие компоненты из `src/components/`.

Действия:

- добавить SEO title и description;
- собрать props для hero, мессенджеров, формы предварительного расчёта, перечня работ, типов печей, форматов помощи, этапов, стоимости, гарантий, FAQ и финального CTA;
- сохранить единый CTA «Получить расчёт по фото»;
- исключить дистанционную диагностику, неподтверждённые цены, сроки и гарантии.

## 2. Добавить компонент кейсов «до/после»

Файл:

- создать `src/components/cases/cases-before-after-01.astro`.

Действия:

- описать типизированные props;
- вывести карточки с двумя равнозначными областями «До» и «После»;
- предусмотреть реальные изображения как необязательные props;
- при отсутствии подтверждённых фото показывать нейтральную маркированную заглушку, не выдавая её за выполненную работу;
- показать задачу, состав возможных работ и ожидаемый формат результата;
- сделать сетку адаптивной и понятной без JavaScript.

## 3. Добавить недостающие варианты существующих блоков

Файлы:

- при необходимости точечно обновить существующие компоненты в `src/components/features/`, `src/components/quiz/` и `src/components/guarantees/`.

Действия:

- расширять только props и варианты отображения, которые нужны новой странице;
- не менять внешний вид исходной страницы установки;
- не дублировать общие токены и стили.

## 4. Проверить качество контента и интерфейса

Проверки:

- `npm run check`;
- `npm run build`;
- `npx graphify hook-rebuild`;
- запуск `astro dev --background`;
- скриншоты нового маршрута на desktop и mobile;
- визуальная проверка hero, форм, кейсов «до/после», FAQ и финального CTA;
- проверка отсутствия горизонтального скролла и ошибок в консоли.

## 5. Обновить отчёт сборки

Файл:

- обновить `builder.report.md` краткой записью о новом маршруте, переиспользованных компонентах, проверках и оставшихся ручных материалах.

Ручной материал перед публикацией: подтверждённые фотографии реальных кейсов «до/после». До их получения страница использует явно маркированный безопасный fallback.
